# Gói phần mềm bổ sung (.deb)

Chép file `.deb` vào thư mục này, chạy lại `sudo ./build.sh`, gói sẽ được cài sẵn trong Tre.

## Scratch 3 (TurboWarp Desktop)

Scratch không còn trong kho Debian 13. Dùng **TurboWarp Desktop**: chạy được dự án Scratch 3, hoạt động không cần mạng, nhẹ hơn bản gốc.

1. Vào trang phát hành: https://github.com/TurboWarp/desktop/releases
2. Ở bản mới nhất, tải file có đuôi **`amd64.deb`** (Linux, 64-bit).
3. Chép file vào thư mục `goi-them/` này.

Nếu không thêm, học sinh vẫn dùng Scratch trực tuyến tại scratch.mit.edu bằng Firefox.

## Phần mềm riêng của trường

Khi ứng dụng học sinh của **Quản Lý Phòng Máy** có bản Linux, đóng gói thành `.deb` và chép vào đây.
